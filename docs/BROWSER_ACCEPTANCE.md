# 浏览器完整交互验收记录

## 验收定位

V0.3 在规则引擎 32/32 自动化测试通过后，进一步验证浏览器端的可玩闭环。验收对象是实际 DOM、按钮、棋盘点击、动画结束后的状态和页面日志。

## 测试隔离

为了稳定复现随机对局难以直接构造的边界局面，页面仅在 URL 参数 `?e2e=1` 下暴露测试状态注入接口。正式访问不启用该接口；真正的验收步骤仍通过浏览器 DOM 完成点击和断言。

## CI

GitHub Actions 在 Ubuntu 24.04 + Node.js 24 环境中执行 `npm install`、安装 Chromium、运行规则测试和 `npm run test:e2e`。失败时上传 `test-results/` 诊断产物。

## 记录原则

本文件与 Notion 均采用追加记录，不覆盖之前的规则测试和失败记录。
