# 可玩性完善 V0.3

## 本阶段目标
围绕“可复现对局 + 明确可行动作 + 完整规则边界”完善本地双人原型。

## 已落地
- 开局随机种子：每盘自动生成种子，也支持输入指定种子。
- 同一种子可复现双方暗棋真实布局，便于复盘和测试。
- 移动提示统一来自规则层合法目标，不在 UI 重复实现规则。
- 普通移动与吃子位置使用不同提示语义。
- 七类棋子测试覆盖：帅、车、马、相/象、士/仕、炮、兵/卒。
- 组合局面覆盖：马腿、炮架、车路径、己方阻挡、边界。
- 保留 V1.0 规则：暗棋首次行动按 originalType；行动后翻开；原地翻棋结束回合；不使用传统将军/应将。

## 验收标准
- [x] 输入同一 seed 可生成相同布局。
- [x] 不同 seed 可产生不同布局。
- [x] UI 显示当前 seed，可通过重新开局复用。
- [x] 选中棋子后显示合法落点，吃子位置单独标识。
- [x] 七类棋子均有基础规则测试。
- [x] 多棋子组合局面有边界测试。
- [ ] 浏览器手工验收移动提示与种子控件。
- [ ] npm test 实际执行并记录结果。

## 下一步
1. 完成浏览器交互验收。
2. 修正规则测试发现的边界问题。
3. 增加更多暗棋身份组合与残局局面。
4. 再进入联网对战/服务端隐藏真实身份阶段。
