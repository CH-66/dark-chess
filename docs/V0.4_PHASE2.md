# V0.4 第二阶段：联网对战最小闭环

## 目标
在不改变随机暗棋规则核心的前提下，建立可替换的 OnlineSession，并提供最小 WebSocket 服务端。

## 已实现
- Room：最多 2 名玩家，固定 RED / BLACK。
- AuthoritativeGame：服务端保存完整棋子真实身份并执行规则。
- revision：每个接受的游戏命令严格递增。
- commandId：同一玩家重复提交同一 commandId 时返回同一结果，不重复执行。
- Visibility Filter：隐藏棋子的 actualType 不进入客户端视图；服务端 seed 不进入客户端视图。
- resync：客户端携带 lastRevision 获取当前玩家过滤后的快照。
- reconnect：玩家使用原 playerId + sessionToken 恢复原有阵营。
- OnlineSession：提供 create/join/move/reveal/resync/reconnect 等统一会话 API。
- 双 Chromium 上下文网络验收入口。

## 当前刻意不做
- 登录、账号体系
- 自动匹配
- 排位
- AI
- 观战权限
- 商业化
- 服务端持久化

## 下一阶段
把 OnlineSession 真正接入可视棋盘 UI，完成“创建房间/加入房间/房间号展示/联网状态/网络错误/断线重连”的用户可操作界面，再进入部署与公网联调。
