## B. 联网架构

### B1 权威性
- [ ] 客户端只提交 command。
- [ ] 服务端计算 legalTargets。
- [ ] 服务端决定 capture / winner / nextTurn。
- [ ] 客户端不能提交 actualType。

### B2 隐藏身份
- [ ] 服务端内部保存完整 actualType。
- [ ] 对手隐藏棋子的 actualType 不进入客户端 payload。
- [ ] WebSocket 广播事件经过玩家视图过滤。
- [ ] resync 同样经过视图过滤。

### B3 并发与重连
- [ ] 每个命令带 commandId。
- [ ] 每个状态带单调递增 revision。
- [ ] expectedRevision 不匹配时拒绝旧命令。
- [ ] 重连可以从 lastRevision 补事件或获取安全快照。
- [ ] 重复 commandId 不会重复执行移动。

- [x] session / protocol 单元测试已加入。
