# V0.4 本地体验与联网架构验收清单

## A. 本地体验

### A1 开局
- [ ] 默认进入本地双人模式。
- [ ] 随机 seed 可正常生成。
- [ ] 输入固定 seed 后重新开局可复现。
- [ ] URL 分享 seed 后打开页面可恢复相同布局。
- [ ] 移动端首屏无需横向滚动。

### A2 操作反馈
- [ ] 当前回合明确。
- [ ] 当前选中棋子明确。
- [ ] 合法目标高亮。
- [ ] 吃子、翻棋、移动动画不会产生重复操作。
- [ ] 动画期间按钮与棋子操作被锁定。
- [ ] reduced-motion 下不依赖动画完成状态。

### A3 对局信息
- [ ] 对局日志按时间倒序展示。
- [ ] 手数准确。
- [ ] 胜负状态明确。
- [ ] 重新开局清理旧日志。
- [ ] seed 可复制/分享。

### A4 可访问性
- [ ] 棋子和按钮可键盘操作。
- [ ] 关键状态有 aria-label / live region。
- [ ] 颜色不是唯一的信息表达方式。
- [ ] 小屏幕仍能选择目标位置。

## B. 联网架构

### B1 权威性
- [ ] 客户端只提交 command。
- [ ] 服务端计算 legalTargets。
- [ ] 服务端决定 capture / winner / nextTurn。
- [ ] 客户端不能提交 actualType。

### B2 隐藏身份
- [ ] 服务端内部保存完整 actualType。
- [ ] 对手隐藏棋子的 actualType 不进入客户端 payload。
- [ ] WebSocket 广播事件经过玩家视图过滤。
- [ ] resync 同样经过视图过滤。

### B3 并发与重连
- [ ] 每个命令带 commandId。
- [ ] 每个状态带单调递增 revision。
- [ ] expectedRevision 不匹配时拒绝旧命令。
- [ ] 重连可以从 lastRevision 补事件或获取安全快照。
- [ ] 重复 commandId 不会重复执行移动。

### B4 已落地的边界层
- [x] LocalSession 已独立于 UI，继续复用 `src/game.js`。
- [x] Online 协议 envelope 已定义 `protocolVersion/gameVersion/commandId/expectedRevision`。
- [x] Resync 请求已定义 `lastRevision`。
- [x] session / protocol 单元测试已加入。
- [x] OnlineSession WebSocket 实现。
- [x] 服务端 Room / AuthoritativeGame 实现。
- [x] Visibility Filter 实现。
- [x] 两浏览器真实联网验收（测试已提交，CI 结果以最新 run 为准）。
